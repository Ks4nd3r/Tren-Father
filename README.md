# Дневник тренировок

Локальное приложение для Android и компьютера. Тренировки хранятся в SQLite в каталоге данных приложения. Интернет и аккаунт не нужны.

## Как пользоваться

1. Введите дату в формате `ГГГГ-ММ-ДД`.
2. Выберите группу мышц и упражнение, нажмите **Открыть упражнение**.
3. Для каждого подхода укажите число повторений и рабочий вес в килограммах. Для упражнений без дополнительного веса укажите `0`.
4. Нажмите **Сохранить упражнение**. Можно выбрать другое упражнение и продолжить запись за ту же дату.
5. В разделе **История** откройте тренировку по дате. Повторное открытие сохранённого упражнения позволяет изменить его подходы.

Группы мышц: грудь, спина, плечи, бицепс, трицепс, квадрицепсы, задняя поверхность бедра, ягодицы, икры и пресс. Это практичнее общего пункта «руки» или «ноги», поскольку прогресс по ним можно будет анализировать отдельно.

**Очистить старые данные** удаляет тренировки, дата которых старше указанного числа дней. Удаление происходит только после нажатия кнопки и подтверждения. База остаётся на устройстве, пока вы не удалите её через приложение или системные настройки Android. При удалении приложения Android обычно удаляет и его данные.

## Архитектура

- `catalog.py` — каталог групп и упражнений.
- `storage.py` — схема SQLite и операции с тренировками.
- `main.py` — интерфейс Kivy.

Таблицы `workouts`, `exercise_entries` и `sets` разделены, поэтому позже можно добавить графики по упражнению, объём нагрузки (`повторы × вес`) и прогноз без переделки существующих записей. При изменении каталога старые тренировки сохраняют свои названия упражнений.

## Запуск на компьютере

Установите Python 3.11 или 3.12, затем:

```sh
python -m pip install -r requirements.txt
python main.py
```

Проверка хранилища:

```sh
python -m unittest discover -s tests
```

## Сборка APK

Buildozer собирает Android-приложение в Linux (например, Ubuntu через WSL2). В корне проекта:

```sh
sudo apt update
sudo apt install -y git zip unzip openjdk-17-jdk python3 python3-pip python3-venv build-essential libffi-dev libssl-dev autoconf automake libtool pkg-config zlib1g-dev libncurses5-dev libncursesw5-dev libtinfo6 cmake autopoint gettext
python3 -m venv .venv
source .venv/bin/activate
pip install buildozer setuptools cython==0.29.34
buildozer android debug
```

Готовый APK появится в `bin/`. Его можно скопировать на телефон и установить, разрешив установку из этого источника. Для личного использования достаточно debug APK; для публикации нужна отдельная release сборка и подпись. Первый запуск сборки скачивает Android SDK/NDK и может занять время.

Сборка настроена только для 64-битных ARM-устройств, включая POCO F5. В GitHub Actions кэшируются загруженные SDK и NDK, поэтому следующие сборки могут идти быстрее.

Если проект размещён на GitHub, можно открыть **Actions → Android APK → Run workflow**. После успешной сборки APK доступен для скачивания как артефакт `workout-diary-apk` на странице запуска.
